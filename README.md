📧 Email Spam Classifier

An end-to-end Machine Learning project that classifies messages as Spam or Not Spam.
This project demonstrates my ability to take an ML idea from data → deployment → user-friendly web app.

🌟 Key Highlights

🔎 Accurate spam detection using NLP techniques.

🧹 Custom text preprocessing pipeline (cleaning, tokenization, stopword removal).

📊 TF-IDF + Machine Learning models for classification.

🎨 Interactive Streamlit web app for real-time predictions.

☁️ Fully deployed on cloud (Render/Azure).

🛠️ Skills & Tools Used
📂 Data & Preprocessing

pandas, numpy → Data cleaning & manipulation

nltk, regex → Text preprocessing

🤖 Machine Learning

scikit-learn → TF-IDF, Naïve Bayes, Logistic Regression

Model evaluation (Accuracy, Precision, Recall, F1-score)

🌐 Deployment

Streamlit → Web app interface

Render / Azure → Cloud deployment

Git, GitHub → Version control

📊 Model Performance

✅ Accuracy: 98%

🎯 Precision: 96%

📩 Recall: 95%

🔄 F1-score: 95.5%
